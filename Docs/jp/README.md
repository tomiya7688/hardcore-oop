# 日本語文書の表記規約

このディレクトリには、Hardcore OOP の日本語説明文書を置く。

## 基本方針

日本語の説明文では、固有名詞を除き、用語に英単語を混在させない。

日本語として定着している外来語は、片仮名で表記する。

ソースコード、識別子、言語の予約語、ファイル名、パス、規則番号は、コード例またはコード表記の中で原文のまま記載してよい。

## 説明文とコード例

説明文では日本語を使用し、言語固有の予約語や構文はコード例として示す。

例:

静的処理の禁止

❌

```csharp
static void Save()
{
}
```

✅

```csharp
sealed class Saver
{
    public void Save()
    {
    }
}
```

説明文中で「static 処理は禁止」のように英単語を混在させるのではなく、「静的処理は禁止」と書き、必要な場合のみコード例で `static` を示す。

## 推奨する用語

説明文では、可能な限り次の日本語表現を用いる。

- 開始点
- 構築起点
- 依存探索
- 公開
- 静的
- 単一実体
- 分岐
- 取得処理
- プロパティ
- オーバーロード
- 任意依存
- 可変
- 不変

## 固有名詞

Hardcore OOP、C#、Java、GitHub などの固有名詞は原表記を使用してよい。

## 優先順位

日本語の説明として自然であることを優先し、英単語をそのまま日本語文中の専門用語として使用しない。
