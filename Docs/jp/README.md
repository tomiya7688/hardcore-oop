# 日本語文書の表記規約

このディレクトリには、Hardcore OOP の日本語説明文書を置く。

## 基本方針

日本語の説明文では、固有名詞を除き、用語に英単語を混在させない。

日本語として定着している外来語は、片仮名で表記する。

ソースコード、識別子、言語の予約語、ファイル名、パス、規則番号は、必要に応じて原文のままコード表記で記載してよい。

## 用語

説明文では、可能な限り次の日本語表現を用いる。

- Entry Point: 開始点
- Composition Root: 構築起点
- Service Locator: 依存探索
- Public: 公開
- static: 静的
- Singleton: 単一実体
- switch: 分岐
- getter: 取得処理
- property: プロパティ
- overload: オーバーロード
- optional dependency: 任意依存
- mutable: 可変
- immutable: 不変

ただし、言語の予約語やコードそのものを示す場合は、`public`、`static`、`null` などの原表記を使用する。

## 固有名詞

Hardcore OOP、C#、Java、GitHub などの固有名詞は原表記を使用してよい。

## 優先順位

日本語の説明として自然であることを優先し、英単語をそのまま日本語文中の専門用語として使用しない。
